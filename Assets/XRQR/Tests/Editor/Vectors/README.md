# XRQR conformance vectors

Copied unchanged from the XRQR repository, `crates/xrqr-conformance/vectors/`, at `v0.7.0-alpha`
(commit `d0b0288`, specification draft 0.7). `ConformanceTests.cs` runs every file against the C#
core in `Assets/XRQR/Runtime/Core`.

The files are licensed AGPL 3.0 or later, as the XRQR repository is. The keys in `keys.json` are
the published RFC 8032 test keys and serve tests only.

To update, copy the directory again from the XRQR tag the client follows and record the tag here.
